Веб-сайт с коллекцией из шести увлекательных мини-игр для развлечения и развития различных навыков.

## 🎮 О проекте

Сайт предлагает пользователям шесть различных мини-игр:
- **Угадай число** - попробуйте угадать случайное число от 1 до 100
- **Простая арифметика** - решайте простые математические задачи
- **Переверни текст** - вводите текст, который будет перевернут
- **Камень, ножницы, бумага** - классическая игра против компьютера
- **Простая викторина** - отвечайте на вопросы с вариантами ответов
- **Генератор случайных цветов** - меняйте фон страницы случайными цветами

## 🛠️ Используемые технологии


- **HTML5** - структура веб-страницы
- **CSS3** - стилизация и адаптивный дизайн
- **JavaScript** - интерактивность и логика игр
- **Google Fonts (Montserrat)** - шрифты для улучшения визуального восприятия
- **SVG** - векторная графика для декоративных элементов
